# Codebase scout

Use this skill for fast, read-only repository mapping.

## Preferred model
Terra/Luna or the fastest low-cost equivalent, low reasoning.

## Procedure
1. Search before reading large files.
2. Identify the smallest relevant files, symbols, tests, and call sites.
3. Report current behavior, extension points, and likely affected tests.
4. Do not propose a security design unless asked; flag security-sensitive findings for the primary agent.
5. Keep output compact.

## Output
- Relevant files/symbols
- Current data/control flow
- Existing tests
- Risks/unknowns
- Suggested next files to inspect
